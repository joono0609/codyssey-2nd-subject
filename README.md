# Python 콘설 퀴즈 게임

## 1. 프로젝트 개요

Python 기본 문법 과 객체지향 프로그램을 활용하여 터미널에서 실행하는 퀴즈 게임을 개발하고 Git 과 GitHub 를 사용하여 기능 과 기능별 변경이력을 기록하여 협업한다

## 2. 퀴즈 주제 및 선정 이유
**퀴즈 주제** Python 문법
**선정 이유** 인공지능에서 많이 활용하는 프로그램 언어인 Python 좀 더 알기 위해 선정
**문항 수** 5 문항 이상(각 문항은 문제 , 선택지 4개 , 정답)
